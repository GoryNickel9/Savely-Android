# Savely Android

Piano per un'app Android nativa di Savely, con APK distribuibile direttamente e gli stessi account e dati della versione web.

Stato al 11 ottobre 2026: documentazione iniziale. Nessun codice applicativo, APK o workflow Android è stato implementato.

| Documento | Contenuto |
|---|---|
| [ROADMAP.md](ROADMAP.md) | Fasi, attività, dipendenze, subagent, stime e criteri di completamento |
| [docs/FEATURE_PARITY.md](docs/FEATURE_PARITY.md) | Inventario delle funzioni e procedura per confrontare Android e web |
| [docs/DEVELOPMENT_AND_TESTING.md](docs/DEVELOPMENT_AND_TESTING.md) | Processi di sviluppo, test e informazioni documentate su PokerStars |

La repository [Savely](https://github.com/GoryNickel9/Savely) resta invariata. Schermate e logica Android saranno realizzate in Kotlin e Jetpack Compose; l'app accederà alle API senza caricare le pagine del sito.
